## 🚀 Características

- 📰 **Noticias Actuales:** Contenido ambientado en 2026 (GTA VI, League of Legends, eSports, Nintendo Switch 2, PS5 Pro).
- 🌑 **Diseño Dark/Neón:** Interfaz moderna con colores vibrantes (Cian y Magenta) ideal para la comunidad gamer.
- 📱 **Totalmente Responsive:** Se adapta perfectamente a computadoras, tablets y teléfonos móviles.
- ⚡ **Rápido y Ligero:** Construido con HTML, CSS y JavaScript puro (Vanilla JS), sin frameworks pesados.
- 🔍 **Sidebar Interactivo:** Sección de "Más Leído" y enlaces directos a las redes sociales oficiales.
- ✉️ **Newsletter:** Sección de suscripción integrada.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido desde cero utilizando tecnologías web estándar:

- **HTML5:** Estructura semántica.
- **CSS3:** Diseño con Flexbox, CSS Grid, Variables de CSS (Custom Properties) y animaciones.
- **JavaScript (Vanilla):** Interactividad del menú móvil, filtros y animaciones de scroll.
